# Site do Dr. Henrique Carmelo

Site de apresentação do médico Henrique Carmelo Dias (CRM-SP 239996). Consultas médicas on-line, por vídeo.

Endereço: https://www.drhenriquecarmelo.com.br (GitHub Pages; o arquivo `CNAME` liga o domínio).

## Estrutura

- `index.html`: página inicial (Início, Sobre, A consulta, Dúvidas e Contato).
- `blog/`: lista de conteúdos e uma página própria para cada texto publicado (`blog/<nome-do-texto>/`).
- `politica-de-privacidade/`: política de privacidade (LGPD).
- `404.html`: página de erro para endereços inexistentes.
- `sitemap.xml` e `robots.txt`: para a Pesquisa Google.
- `assets/`: logo, fotos e imagens de compartilhamento (`assets/og/`).

Os arquivos são gerados pelo Claude a partir do modelo do site. Não edite as páginas à mão: peça a alteração ao Claude, que gera tudo de novo e mantém as páginas iguais entre si.

## Blog

- Só textos aprovados pelo Henrique entram no site.
- Rascunhos ficam fora deste repositório, numa pasta privada no computador do Paulo, e não aparecem no código público.
- Nada é publicado automaticamente por data: um texto novo só entra quando o Claude gera o site de novo depois da aprovação.
